Neumetik MIDI

MIDI music for games, with no SoundFont. Every instrument is synthesized as it plays, so the whole General MIDI and GS synthesizer downloads in about 65 KB. No dependencies, no audio API: it turns MIDI into samples and your engine plays them.

Choosing a lightweight MIDI option

Most game frameworks (LÖVE, Phaser, raylib, Godot, MonoGame, libGDX, Heaps) can't play a .mid file out of the box. These are the usual ways to add it, and what each costs.

A General MIDI SoundFont is typically 6 to 150 MB (GeneralUser GS is about 30 MB, FluidR3_GM about 140 MB). The third-party details above are a summary: confirm licenses and sizes with each project before you ship.

Pick Neumetik MIDI when

  • download size matters: a web game, a game jam, mobile;
  • the music should react: loops, layers muted and unmuted, tempo, fades, notes played over it;
  • you want one synth on every platform that sounds the same everywhere (its output is deterministic);
  • your license must be permissive (MIT) with no SoundFont license to check.

Pick a SoundFont synth when

  • realism matters most: orchestral scores, a solo acoustic instrument;
  • the music was written for one particular sound set and must sound like it;
  • a few megabytes more doesn't matter to your players.

What it plays

  • Standard MIDI Files, formats 0, 1 and 2, and RIFF RMID
  • General MIDI's 128 instruments and its drum map (keys 27 to 87)
  • Roland GS: variation tones, drum kits, rhythm parts on any channel, GS reset
  • Classic synth banks 80, 81 and 82; XG's drum bank (127)
  • Volume, expression, pan, sustain, modulation, brightness, resonance, reverb, chorus
  • Pitch bend and its range, fine and coarse tuning (RPNs)
  • Loop points: loopStart/loopEnd markers, or CC 111
  • 64 voices; the quietest is stolen when they run out

Not supported: SoundFonts and DLS, GM2 and XG voice banks, NRPN sound editing, MIDI 2.0.

Get started

// Cargo.toml: neumetik-midi = "0.1"
use neumetik_midi::Player;

let mut music = Player::new(48_000);
music.load(&std::fs::read("overworld.mid")?)?;
music.set_looping(true);       // between its loopStart/loopEnd markers
music.play();

// In your audio callback:
music.render_interleaved(&mut buffer);   // &mut [f32], or render_i16

// Whenever the game wants:
music.fade_to(0.0, 1.5);
music.set_channel_muted(9, true);      // drop the drums
music.synth_mut().note_on(15, 72, 110); // a sting over the music
#include "neumetik_midi.h"   // link libneumetik_midi.a (or the .so/.dylib/.dll)

nm_player *music = nm_create(48000);
if (nm_load(music, midi, midi_size) != NM_OK) { /* nm_error_string(code) */ }
nm_set_looping(music, 1);
nm_play(music);

/* when the stream wants more */
nm_render_f32(music, buffer, frames);    /* or nm_render_s16 */

nm_fade_to(music, 0.0f, 1.5f);
nm_destroy(music);
import { createMusicNode } from './neumetik-midi.js';
